## Frozen Runtime Semantics

- Real Mode with missing keys, incomplete configuration, or provider failure must return readiness failure or an explicit error.
- Real Mode must never silently switch to Mock.
- Local reviewed audio fallback is allowed only as `source_type = matched_fallback`.
- Real provider-generated audio uses `source_type = generated`.
- `hash-v1`, demo Chroma chunks, hard-coded Agent output, simulated music success, and bundled demo audio are not Real evidence.
- Credentials are injected only through deployment secrets/environment variables and are never committed or logged.
