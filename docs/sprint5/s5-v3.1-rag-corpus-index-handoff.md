## Owner promotion inputs

the agreed paths (or pass equivalent absolute paths):

```text

```

The approved manifest must declare `text-embedding-v4`, dimension 1024 through
`text-embedding-v4@1024`, cosine distance, a reviewed minimum score, exact
chunk count and a valid recomputed checksum. Each `KnowledgeChunk` must be
`approved`, carry the approved medical-review version and have a valid
recomputed checksum. No candidate file may be renamed to approved without
that review and release step.

The physical Chroma database is a local Owner artifact and is intentionally
not committed. The receipt is a logical, deterministic record of collection
name, corpus manifest checksum, ordered chunk checksums and index checksum; it
does not contain vectors, prompts, user text, API keys or workspace IDs.

## Owner index build (PowerShell)

Run from the repository root on the Owner computer. Set secret variables by
the Owner's secret-management procedure; do not paste their values into a
terminal transcript, issue, PR or file.

```powershell
if ([string]::IsNullOrWhiteSpace($env:DASHSCOPE_API_KEY)) { throw "DASHSCOPE_API_KEY is not configured" }
if ([string]::IsNullOrWhiteSpace($env:DASHSCOPE_WORKSPACE_ID)) { throw "DASHSCOPE_WORKSPACE_ID is not configured" }

$env:HARMONYAI_REAL_AGENTS = "true"
$env:DASHSCOPE_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1"
$env:EMBEDDING_PROVIDER = "dashscope"
$env:EMBEDDING_MODEL = "text-embedding-v4"
$env:EMBEDDING_DIMENSION = "1024"
$env:CHROMA_PERSIST_DIRECTORY = (Join-Path (Get-Location) ".chroma-v31")
$env:CHROMA_COLLECTION = "harmony_v31"

python -m backend.ai_engine.v3.rag_index_cli `
  --manifest "knowledge/v3/rag-ingestion-manifest-v3.1-approved.json" `
  --chunks "knowledge/v3/rag-corpus-chunks-v3.1-approved.json" `
  --chroma-dir $env:CHROMA_PERSIST_DIRECTORY `
  --collection $env:CHROMA_COLLECTION `
  --receipt ".chroma-v31/index-receipt.json"
```

Expected safe output contains only status, collection, count and checksums.
The command exits non-zero for missing configuration, pending/unapproved
assets, checksum mismatch, wrong embedding identity, provider failure or a
Chroma count mismatch. It never loads the legacy demo chunks and never
silently switches to a Mock Provider.
