# HarmonyAI 用户流程 V2

## 1. 页面数量说明

目标流程包含“AI 分析中”和“可解释评估结果”两个阶段，但 Sprint 3 要求控制为八个页面。因此二者共用同一个“评估结果页”：

- 请求进行中：显示分析中状态；
- 请求成功：切换为可解释结果；
- 请求降级：显示问卷基础评估和降级说明；
- 命中风险：显示安全提示并暂停常规流程。

八个页面为：

1. 欢迎页；
2. 病例上传页；
3. 自由描述页；
4. 图文问卷页；
5. 评估结果页；
6. 音乐处方与播放器页；
7. 多维反馈页；
8. 完成页。

## 2. 全局体验原则

- 用户无需先判断自己的单一情绪；
- 每页只完成一个主要任务；
- 病例和自由描述可跳过，问卷为比赛版必填基线；
- 顶部显示流程进度，但不显示“医学诊断”；
- 页面刷新或返回时，通过 `session_id` 恢复已保存步骤；
- 所有错误状态都提供下一步，不让用户停在死路；
- 不展示大模型内部思维，只展示来源、依据摘要、置信/完整度和降级说明；
- 页面固定提供隐私与非医疗声明入口。

## 3. 页面 1：欢迎页

### 目的

解释产品做什么，并将用户带入多源状态评估，不展示五音卡片，也不要求先选情绪。

### 建议文案

主标题：

> 不用先给情绪贴标签，先从你的近况开始

副标题：

> 你可以提供已有健康材料、写下最近发生的事，再完成一份约 3 分钟的状态问卷。HarmonyAI 会整理信息，给出用于音乐调养的状态评估和辅助辨证倾向。

固定提示：

> 本系统不提供医学诊断，不能替代医生或心理专业人员。

### 按钮

- 主按钮：`开始今日状态评估`
- 次按钮：`仅体验基础问卷`
- 文本入口：`隐私与数据使用说明`

### 状态

- 成功：创建或恢复会话，进入病例上传页；
- 快速体验：创建会话并标记材料、描述均跳过，直接进入问卷；
- 错误：显示“暂时无法创建会话”，提供重试；
- 离线演示：使用本地演示会话，明确标记“离线问卷模式”。

## 4. 页面 2：病例上传页

### 目的

先询问用户是否有医生诊断材料，并允许安全地上传或跳过。

### 建议文案

标题：

> 你是否有可以辅助参考的健康材料？

说明：

> 可上传门诊病历、体检报告或睡眠/情绪相关记录的图片或 PDF。系统只提取其中与你本次状态相关的文字，不会修改医生结论。

隐私提示：

> 上传前请尽量遮挡姓名、身份证号、手机号等信息。比赛版默认只在本次评估中使用原始文件。

### 按钮

- `选择图片或 PDF`
- `开始识别`
- `确认识别文字`
- `重新上传`
- `暂时没有，跳过`

### 成功状态

1. 显示文件名、类型、大小和页数；
2. OCR 后显示提取文字；
3. 用户可修改明显错误；
4. 用户点击确认后，生成 `document_id` 与 `document_text`；
5. 进入自由描述页。

### 跳过状态

- 记录 `document_status=skipped`；
- 不显示警告；
- 进入自由描述页。

### 错误与降级

- 类型不支持：提示仅支持 JPG、PNG、PDF；
- 大小或页数超限：提示压缩、拆分或改传图片；
- PDF 加密/损坏：提示改传截图或跳过；
- OCR 失败：提示“材料暂未识别”，提供“手动补充文字”“重新识别”“跳过”；
- OCR 超时：自动标记 `degraded`，主流程不阻断；
- 命中危险信息：在用户确认后由安全规则二次检查。

## 5. 页面 3：自由描述页

### 目的

让用户用自己的语言表达近况，而不是先选“怒喜思悲恐”。

### 建议文案

标题：

> 和我说说最近发生了什么

说明：

> 可以写下最近的事情、压力、身体感受、睡眠或饮食变化，不需要先判断自己属于哪种情绪。

输入框占位：

> 例如：最近要考试了，躺下后脑子总停不下来，白天很累，胃口也不太好……

辅助示例：

- 最近总是睡不好，脑子停不下来；
- 和朋友争执后一直很烦躁；
- 最近什么都不太想做，感觉很累。

### 按钮

- 主按钮：`保存并继续`
- 次按钮：`暂时不想写，跳过`
- 文本按钮：`清空`

### 状态

- 成功：保存清理后的 `narrative_text`，进入问卷；
- 跳过：记录 `narrative_status=skipped`；
- 输入过短：允许继续，但提示“多写一点事件或身体感受会更容易理解”；
- 输入超长：显示剩余字数，达到上限后不再输入；
- 命中高风险词：立即显示安全提示，后端仍需复核；
- Qwen 状态不在本页阻断，真正分析在问卷提交后进行。

## 6. 页面 4：图文问卷页

### 目的

用 12 个简短问题建立稳定、可降级的评估基线。

### 建议文案

标题：

> 再用约 3 分钟，了解你过去 7 天的状态

提示：

> 没有标准答案，请选择最接近真实情况的一项。

### 交互

- 一页一题；
- 天气、海面、电池和身体感受使用图形卡；
- 核心题显示 0—4 频率和文字解释；
- 顶部显示进度；
- 返回时保留答案；
- Q12 高风险项选中后立即显示安全说明。

### 按钮

- `上一题`
- `下一题`
- 最后一题：`提交并分析`
- 风险提示中的：`我选错了，返回修改`

### 状态

- 成功：前端提交原始答案，后端复算得分，进入评估结果页加载态；
- 未答：指出具体题目，不允许提交；
- 网络失败：保留答案，提供重试；
- 快速体验：同样必须完成问卷；
- 高风险：后端确认后进入结果页安全状态，不执行普通音乐处方。

## 7. 页面 5：评估结果页

### 7.1 AI 分析中状态

标题：

> 正在整理你提供的信息

展示步骤：

- 状态评估 Agent：整理材料、描述和问卷；
- 辅助辨证 Agent：等待用户确认后执行；
- 音乐处方 Agent：等待中；
- Music Agent：等待中。

说明：

> 页面只展示处理进度，不展示模型内部推理过程。

按钮：

- 超时前无主按钮；
- 超时后：`切换到基础问卷评估`
- `返回检查问卷`

### 7.2 可解释结果状态

标题：

> 这是系统对你当前状态的理解

建议内容：

- 主要状态：如紧张、反复思虑；
- 伴随状态：如疲惫、睡眠困扰；
- 事件与诱因；
- 身体和生活表现；
- 过去 7 天频率；
- 使用来源标签：问卷、自由描述、已确认材料；
- 依据摘要；
- 信息冲突、缺失和降级说明；
- 信息完整度或系统匹配度；
- 固定非诊断声明。

确认文案：

> 这像你现在的状态吗？

按钮：

- `基本符合，继续`
- `部分符合，我要调整`
- `返回补充信息`

### 7.3 降级状态

文案：

> 自由描述的 AI 分析暂时不可用，已根据你的问卷完成基础状态评估。你仍然可以继续体验后续音乐调养流程。

按钮：

- `继续基础评估`
- `稍后重试 AI 分析`

### 7.4 安全状态

文案：

> 你提供的信息中出现了需要优先关注的信号。音乐调养不能代替及时的专业帮助。

处理：

- 展示正式配置的安全建议；
- 对急性身体危险提示尽快寻求急救或线下医疗；
- 对自伤风险展示合规危机支持入口；
- 不出现“继续生成普通处方”的默认主按钮；
- 允许用户返回修改误选。

## 8. 页面 6：音乐处方与播放器页

### 目的

将辅助辨证倾向、音乐处方参数和本地音频播放放在同一页，让评委看到 Agent 链路，而不是只看到一首歌。

### 建议文案

辅助辨证卡：

> 主要辅助辨证倾向：心脾两虚倾向  
> 依据：反复思虑、睡眠不稳、精力不足和食欲变化。  
> 此结果用于音乐调养参考，不构成医学诊断。

处方卡：

- 处方名称；
- 主音/调式；
- BPM；
- 乐器；
- 环境音；
- 建议时长；
- 使用场景；
- 参数来源解释。

Music Agent 卡：

- 来源类型：`source_type=matched`，即本地曲库匹配；
- `music_id`、曲目名称和 `stream_url`；
- 匹配参数；
- 音频来源/版权说明；
- 降级信息。

### 按钮

- `开始播放`
- `暂停`
- `不喜欢当前音乐`
- `结束并反馈`
- 音频失败时：`播放备用曲目`

### 状态

- 成功：先收集听前状态，再开始播放；
- 处方降级：明确说明使用基础规则；
- 本地音频失败：切换备用曲目；
- 用户感到不适：停止播放并进入反馈页；
- 不宣称当前音乐由 SkyMusic 实时生成。

## 9. 页面 7：多维反馈页

### 目的

收集听后状态与音乐体验，为个人偏好提供依据。

### 建议文案

标题：

> 听完之后，你现在感觉怎么样？

提示：

> 这些变化来自你的主观感受，只用于调整你的个人体验。

### 字段

- 听后紧张、身体紧绷、精神疲劳 0—10；
- 明显好转 / 有一点好转 / 没变化 / 更不舒服；
- 1—5 星；
- 放松程度 1—5；
- 音乐匹配度 1—5；
- 是否愿意继续使用；
- 是否收藏；
- 不喜欢的音乐特征；
- 选填文字反馈。

### 按钮

- `提交反馈`
- `暂不填写文字，直接提交`
- `返回播放器`

### 状态

- 成功：显示本次主观变化和个人偏好调整摘要，进入完成页；
- 保存失败：保留内容并重试；
- Qwen 失败：使用确定性变化计算和个人偏好规则；
- 更不舒服：提示停止相似音乐，并允许选择不喜欢的元素；
- 反馈不会修改全局医学知识规则。

## 10. 页面 8：完成页

### 目的

完成一次闭环，给出简短总结和可继续操作。

### 建议文案

标题：

> 本次音乐调养已完成

摘要：

- 本次主要状态；
- 使用的辅助辨证倾向；
- 播放曲目；
- 用户主观前后变化；
- 已记录的个人偏好；
- 降级情况（如有）。

示例：

> 你反馈紧张程度从 7 降到 5。系统已记录你希望减少高频笛声、保留古琴的偏好。以上为个人主观体验记录。

### 按钮

- `完成`
- `再次播放`
- `查看本次详情`（P1）
- `开始新的评估`

### 状态

- 会话标记为 `completed`；
- 若反馈未保存，完成页不得显示“已记录偏好”；
- 离线模式显示“本次结果仅保存在当前设备/会话”的真实状态。

## 11. OCR 与 Qwen 降级路径

### 11.1 OCR 失败

```text
上传材料
  → OCR失败
  → 手动补充识别文字 / 重试 / 跳过
  → 自由描述
  → 问卷
  → 评估
```

材料失败不降低问卷分数，只降低信息来源完整度。

### 11.2 Qwen 失败

```text
材料确认文本 + 自由描述 + 问卷
  → Qwen超时或格式错误
  → 重试一次
  → 仍失败
  → 丢弃未验证的LLM输出
  → 使用问卷确定性分数 + 已审核本地规则
  → 展示“基础问卷评估”标记
```

### 11.3 OCR 与 Qwen 同时失败

```text
问卷
  → 本地计分
  → 本地辅助辨证规则
  → 本地音乐处方
  → 本地曲目
  → Feedback 2.0
```

该路径必须作为比赛现场的离线保底演示。

## 12. 页面路由兼容建议

当前 `pages.json` 只有 `index`、`emotion`、`survey`、`player` 四页。Sprint 3 应新增 v2 页面并将欢迎页设为主入口，但在比赛版本稳定前保留旧页面：

- 旧 `/pages/emotion/emotion` 可保留为快速模式；
- 旧 `/pages/survey/survey` 不直接删除，避免破坏已有演示；
- 旧 `/pages/player/player` 可由 v2 播放器复用音频逻辑；
- v2 页面应使用新的会话状态，避免与旧本地缓存字段冲突。

是否最终移除旧入口应在 Sprint 3 验收后单独决定。
