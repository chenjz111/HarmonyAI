# 非生产 Android 验收清单（2026-10-25）

本清单不是执行授权。所有设备项目当前 NOT RUN；仅在 Owner 后续批准工具、依赖、Origin、签名及安装后执行。

## 前置条件

- 确认 DCloud AppID、包名、HBuilderX/SDK 配对与产物来源；审查权限、备份规则、签名及插件源码/依赖。
- 获批的非生产 HTTPS 后端、可验证证书及隔离数据库；只使用合成身份、资料与合法非生产音频，不调用付费 Provider。
- 对 request、upload、download 验证错主机、过期、不受信任证书均拒绝；跨域/同域/协议重定向不发送第二次凭据；无环境 Cookie、日志/备份无令牌。
- Keystore 适配器真实并发 take、原子写入、进程杀死、密钥失效、卸载重装、备份恢复均验证，无明文 fallback。
- 后端账号路由和前端功能仅在另行批准的非生产配置中启用；默认 Live Flags 不变。

## 未知绑定结果且 Guest 已失效：仅候选交互合同

保留 binding 隔离状态和原身份归属，不因 401 推断绑定失败、不创建替代 Guest。候选提示为“绑定结果尚未确认，原有历史暂不可访问”；提供“尝试登录”和“稍后重试”。“明确放弃恢复并新建游客”仅列为待批准设计：须说明旧历史不会转移且可能无法找回、二次明确确认、原恢复记录处理规则。未获 Owner 决策前不实现该身份替换按钮或清理动作。登录也不得合并其他身份数据。

## 音乐能力与账号的真实依赖

合法 Guest 的历史、收藏、Player、反馈不要求先开放注册账号；它们需要可靠身份恢复、获批 HTTPS 网络、真实资产与安全音频访问，以及单独批准的非生产音乐库配置。Registered 额外依赖账号路由、Keystore、Refresh 旋转与注销接线。两者不能共用一个“账号测试通过”结论代替验收。合成音频证明传输/页面，不证明真实生成质量；现有测试音频不得标成生成结果。

H5 仍需 HTTPS、HttpOnly/Secure/SameSite Cookie、会话绑定 CSRF、Origin 和 credentialed CORS 白名单，不能复用 Android Bearer 方案宣称完成。Guest 浏览器存储整改亦保留。
