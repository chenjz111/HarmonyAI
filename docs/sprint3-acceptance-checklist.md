# HarmonyAI Sprint 3 验收清单

> 使用方式：每项必须记录测试人、日期、环境和证据链接。标记为 P0 的项目未通过时，不得宣布比赛版完成。

## 1. 验收环境

- [ ] 记录前端运行方式和版本
- [ ] 记录后端 Python 版本、依赖版本和启动命令
- [ ] 记录数据库类型与迁移版本
- [ ] 记录 Qwen 开启/关闭方式，不记录 API Key
- [ ] 记录 OCR Provider 和离线降级方式
- [ ] 准备至少一台目标手机或小屏浏览器
- [ ] 准备比赛现场网络正常、网络异常两种环境
- [ ] 准备已授权的本地演示音频

## 2. 前端验收

### 2.1 入口与导航

- [ ] 首屏不展示五音卡片作为主操作
- [ ] 首屏不要求用户先选择单一情绪
- [ ] 主流程共八个页面
- [ ] 欢迎页可进入完整流程
- [ ] 欢迎页可进入基础问卷快速体验
- [ ] 返回上一页不会丢失当前输入
- [ ] 页面刷新后可通过 `session_id` 恢复合理步骤
- [ ] 旧页面保留期间不会与 v2 本地缓存冲突

### 2.2 病例上传

- [ ] JPG 可选择、预览和上传
- [ ] PNG 可选择、预览和上传
- [ ] 限定范围 PDF 可上传
- [ ] 非法类型有明确提示
- [ ] 文件过大有明确提示
- [ ] PDF 页数超限有明确提示
- [ ] 用户可跳过
- [ ] OCR 文本可确认
- [ ] OCR 失败可重试、手动补充或跳过
- [ ] 页面显示隐私提示

### 2.3 自由描述

- [ ] 输入框文案不要求用户先判断情绪
- [ ] 有事件、压力、身体、睡眠等示例
- [ ] 字数限制清晰
- [ ] 用户可以跳过
- [ ] 空白字符按空输入处理
- [ ] 超长内容不会导致页面或接口异常
- [ ] 高风险词触发前端提示，且后端仍会复核

### 2.4 问卷与结果

- [ ] 问卷进度正确
- [ ] 选项触控区域足够
- [ ] 图形均有文字标签
- [ ] 颜色不是唯一信息载体
- [ ] 未答题不能提交，并能定位缺失题
- [ ] 分析中状态清晰
- [ ] 超时可切到基础问卷评估
- [ ] 结果展示来源标签、依据和降级信息
- [ ] 结果固定显示非诊断声明
- [ ] 用户可确认、部分修正或返回补充

### 2.5 播放、反馈和完成

- [ ] 播放前收集听前状态
- [ ] 显示处方参数和匹配解释
- [ ] 明确写“本地曲库匹配”
- [ ] 播放、暂停和结束正常
- [ ] 音频失败可切换备用曲目
- [ ] 用户可主动报告不适
- [ ] Feedback 2.0 字段完整
- [ ] 反馈保存失败时表单不丢失
- [ ] 完成页仅展示实际保存成功的偏好
- [ ] 小屏无横向溢出和按钮遮挡
- [ ] 控制台无阻断性错误

## 3. 后端验收

### 3.1 v1 回归

- [ ] `/api/v1/assessment` 旧请求仍可用
- [ ] `/api/v1/diagnosis` 旧请求仍可用
- [ ] `/api/v1/prescription` 旧请求仍可用
- [ ] `/api/v1/generation` 仍能返回本地音频
- [ ] `/api/v1/feedback` 旧请求仍可用
- [ ] 原 47 个后端测试全部通过
- [ ] 旧前端结构测试通过或按明确迁移方案更新

### 3.2 v2 契约

- [ ] 所有请求使用明确 Pydantic Schema
- [ ] 所有响应使用统一外壳
- [ ] 错误码、用户文案和 `retryable` 一致
- [ ] `session_id` 能串联全流程
- [ ] 会话查询返回步骤、Agent 和降级摘要
- [ ] 会话查询默认不返回病例全文
- [ ] ID 在并发和同日多次请求下保持唯一
- [ ] v2 JSON 示例可被解析

### 3.3 上传与存储

- [ ] 通过 MIME 和文件签名双重校验
- [ ] 限制大小、PDF 页数和处理时长
- [ ] 拒绝加密或损坏 PDF
- [ ] 原始文件采用临时存储
- [ ] 临时文件按策略清理
- [ ] OCR 原文未经用户确认不作为可靠输入
- [ ] 日志不记录完整原文或直接身份信息
- [ ] 数据库使用增量迁移，不执行破坏性 DROP
- [ ] 迁移可回滚并在副本验证

### 3.4 稳定性

- [ ] OCR 超时不会拖死工作进程
- [ ] Qwen 超时有一次受控重试
- [ ] 非法模型 JSON 被 Schema 拒绝
- [ ] 反馈保存失败不返回成功
- [ ] 本地音频不存在时返回可处理错误
- [ ] 重复反馈提交具备幂等策略

## 4. AI 与 Agent 验收

### 4.1 Assessment Agent

- [ ] 标准 ID 为 `assessment_agent`
- [ ] 兼容读取 `evaluation_agent` 旧记录
- [ ] 能处理仅问卷输入
- [ ] 能处理问卷 + 自由描述
- [ ] 能处理问卷 + 已确认材料
- [ ] 能处理三种来源
- [ ] 输出 `sources_used`
- [ ] 输出状态摘要、维度、诱因、身体状态和证据
- [ ] 输出冲突和缺失信息
- [ ] 问卷确定性分数不会被 Qwen 改写
- [ ] Qwen 失败后为 `degraded/questionnaire_only`

### 4.2 Diagnosis 与 Prescription

- [ ] 用户端名称为“辅助辨证 Agent”
- [ ] 输出只称“辅助辨证倾向”
- [ ] 单一身体选项不会直接决定证型
- [ ] 低可信或冲突状态有警告
- [ ] 每个倾向有可理解的依据摘要
- [ ] 处方输出调式、BPM、乐器、时长和解释
- [ ] 知识检索失败可退回已审核本地规则

### 4.3 Music Agent

- [ ] 输出 `source_type=matched`
- [ ] P0 只返回 `matched`
- [ ] 输出 `music_id`、`title`、`stream_url`、`mode`、`bpm`、`duration_seconds`、`instruments` 和来源
- [ ] 输出结构化音乐参数
- [ ] 输出匹配解释
- [ ] 不把本地曲目描述为实时 AI 生成
- [ ] 备用曲目已验证

### 4.4 Feedback Agent

- [ ] 不再在用户交互前自动写入默认 4 星
- [ ] 输出听前听后 delta
- [ ] 输出体验摘要
- [ ] 输出 `personal_preference_patch`
- [ ] 固定输出 `global_rule_update=false`
- [ ] Qwen 失败后可用确定性规则运行
- [ ] 反馈冲突不会被擅自改写

## 5. 问卷验收

- [ ] 总计 12 题
- [ ] 5 名非项目成员试答的中位时间不超过 3 分钟
- [ ] Q2—Q11 均为过去 7 天、0—4 频率量表
- [ ] 覆盖紧张担忧
- [ ] 覆盖思虑过多
- [ ] 覆盖烦躁易怒
- [ ] 覆盖情绪低落
- [ ] 覆盖兴趣下降
- [ ] 覆盖恐惧不安
- [ ] 覆盖睡眠
- [ ] 覆盖精力
- [ ] 覆盖食欲
- [ ] 覆盖日常影响
- [ ] 至少 3 题为图形或图标卡片
- [ ] 天气题不进入核心计分
- [ ] 身体题不直接映射脏腑、证型或调式
- [ ] 后端能从原始答案稳定复算分数
- [ ] 同一份答案重复提交得到同一问卷分数
- [ ] 输出没有疾病确诊用语

## 6. 反馈验收

- [ ] 保留 1—5 星
- [ ] 听前紧张程度可记录
- [ ] 听后紧张程度可记录
- [ ] 身体紧绷和精神疲劳可记录
- [ ] 主观变化标签可选
- [ ] 放松程度可评分
- [ ] 音乐匹配度可评分
- [ ] 是否继续使用可选择
- [ ] 是否收藏可选择
- [ ] 不喜欢特征可多选
- [ ] 不喜欢的乐器可记录
- [ ] 文字反馈可留空且最长 500 字
- [ ] 播放行为由后端合理复核
- [ ] 保存历史原始反馈，不覆盖
- [ ] 个人偏好可以更新和撤销
- [ ] 任何反馈都不能自动修改全局医学规则
- [ ] 页面明确显示“用户主观反馈”
- [ ] 页面明确说明五星评价不能证明辅助辨证结果正确

## 7. 隐私与安全验收

- [ ] 上传前取得明确同意
- [ ] 提示用户遮挡身份信息
- [ ] 明确文件用途和保留时间
- [ ] 原始病例不写入普通日志
- [ ] API Key 不出现在代码、日志、文档或截图
- [ ] 自伤风险有确定性规则
- [ ] 严重胸痛有确定性规则
- [ ] 明显呼吸困难有确定性规则
- [ ] 风险规则覆盖问卷、自由描述和已确认 OCR 文本
- [ ] Qwen 关闭时风险规则仍生效
- [ ] 高风险状态阻断普通音乐处方
- [ ] 不建议用户停药、换药
- [ ] 不承诺治愈或临床效果
- [ ] 所有结果页有非诊断声明
- [ ] 正式上线前由老师/医学负责人审核安全文案

## 8. 三条端到端场景

### E2E-01：三源齐全，在线成功

输入：

- 上传一份预设的、已脱敏的睡眠相关材料；
- 自由描述：“最近要考试，晚上脑子停不下来，白天很累，胃口不太好”；
- 问卷中紧张、思虑、睡眠、精力较高。

预期：

- [ ] OCR 成功并要求确认
- [ ] 三种来源均显示为已使用
- [ ] Assessment 识别紧张、反复思虑、睡眠和精力变化
- [ ] 用户修正“不是特别害怕”
- [ ] 辅助辨证依据随确认更新
- [ ] 输出结构化音乐处方
- [ ] Music Agent 标记 `matched`
- [ ] 本地音频可播放
- [ ] 听前 7、听后 5 的主观变化正确计算为 -2
- [ ] 不喜欢高频笛声只更新个人偏好
- [ ] 完成页摘要准确

### E2E-02：无材料、无自由描述、Qwen 不可用

操作：

- 跳过病例；
- 跳过自由描述；
- 完成 12 题问卷；
- 关闭 Qwen 配置或使用可控失败 Provider。

预期：

- [ ] 跳过操作无错误和责备性文案
- [ ] 问卷分数可确定性计算
- [ ] Assessment 为 `degraded`
- [ ] `analysis_mode=questionnaire_only`
- [ ] 页面说明已切换基础问卷评估
- [ ] 本地辅助辨证、处方、曲目、反馈仍能完成
- [ ] 不出现伪造的 Qwen 结果

### E2E-03：OCR 失败并命中安全风险

操作：

- 上传一份模拟 OCR 失败的文件；
- 选择跳过或手动输入；
- 在问卷选择“严重或持续胸痛”或“明显呼吸困难”；
- 另运行一例自伤风险自由描述。

预期：

- [ ] OCR 失败可重试、手动或跳过
- [ ] OCR 失败不阻断问卷
- [ ] 高风险规则在无 Qwen 时仍触发
- [ ] 显示正确安全提示
- [ ] 普通处方和音乐播放被暂停
- [ ] 用户可返回修改误选
- [ ] 日志只保存风险代码，不打印敏感原文
