# 七音→五音映射方案

> 版本：V1.0  
> 日期：2026-07-11  
> 状态：已确认

---

## 1. 核心问题

西方七声音阶（Do/Re/Mi/Fa/Sol/La/Si）如何映射到中医五音（宫/商/角/徵/羽），以支撑音乐生成中的调式约束。

---

## 2. 学术依据

### 2.1 主要文献

| 文献 | 年份 | 来源 | 核心观点 |
|------|------|------|----------|
| 《五行音乐疗法及其择时应用探析》 | 2024 | 《山东中医杂志》 | **五音治疗体系由五声调式、六声调式与七声调式共同构成** |
| 《中医五行音乐疗法的研究进展》 | — | — | 运用宫、商、角、徵、羽五个声阶来调节五脏，治疗理论建立在五音上而非建立在七音上 |

### 2.2 关键发现

- 国内中医音乐疗法研究**没有认为七声音阶不能用**
- 学术界**没有形成"必须删除 Fa 和 Si"的统一观点**
- 治疗理论建立在五音上，但不排斥七声
- 现有研究聚焦于"五音对应五脏"，未专门论证七声音阶需要删减

---

## 3. 设计方案：三层约束架构

### 3.1 架构总览

```
辨证Agent（②）               处方Agent（③）                   生成Agent（④）
┌──────────────────┐      ┌───────────────────────┐      ┌──────────────┐
│ 输出：调式决策    │      │ 输出：结构化音乐Prompt  │      │ 执行AI生成   │
│                  │      │                       │      │              │
│ 主调: 角 (Mi)    │ ───→ │ 调式约束：角调式       │ ───→ │ Fa出现在装饰音│
│ 权重: 80%        │      │ 音阶策略：五声为主体    │      │ 中可接受     │
│ 辅调: 宫 (Do)    │      │ 扩展策略：允许经过音、  │      │              │
│ 权重: 20%        │      │          装饰音        │      │              │
│                  │      │ 乐器：古琴 + 竹笛       │      │              │
│                  │      │ BPM：65                │      │              │
└──────────────────┘      └───────────────────────┘      └──────────────┘
```

### 3.2 职责分离

| 层 | 智能体 | 职责 | 核心原则 |
|----|--------|------|----------|
| **决策层** | ② 中医辨证Agent | 决定"什么调式、什么权重" | 基于中医理论，输出主调+辅调 |
| **翻译层** | ③ 音乐处方Agent | 将调式决策翻译为音乐约束 | 五声音阶为主体，允许扩展 |
| **执行层** | ④ 音乐生成Agent | 执行AI生成 | 容忍少量变声，不强制禁止 |

### 3.3 核心原则

> **调式中心决定疗愈方向，音阶约束是手段不是目的。**
>
> Fa 和 Si 不是"敌人"——没有医学文献证明它们对疗愈有害——
> 它们只是不在五音理论的内核里，但可以作为经过音和装饰音存在。

## 4. 五音基础映射表

### 4.1 五音与西方音名对应

| 五音 | 西方音名 | 相对音高（以宫=C为基准） | 
|------|----------|-------------------------|
| 宫 | C (Do) | 基准音 |
| 商 | D (Re) | 大二度 |
| 角 | E (Mi) | 大三度 |
| 徵 | G (Sol) | 纯五度 |
| 羽 | A (La) | 大六度 |

### 4.2 五种调式的五音构成

> 五种调式共用同一音池 {C, D, E, G, A}，区别在于哪个音做主音。

| 调式 | 主音 | 该调式中五音位置 | 音阶（首调唱名） |
|------|------|-----------------|-----------------|
| 宫调 | 宫=C | C - D - E - G - A | Do - Re - Mi - Sol - La |
| 商调 | 商=D | D - E - G - A - C | Re - Mi - Sol - La - Do |
| 角调 | 角=E | E - G - A - C - D | Mi - Sol - La - Do - Re |
| 徵调 | 徵=G | G - A - C - D - E | Sol - La - Do - Re - Mi |
| 羽调 | 羽=A | A - C - D - E - G | La - Do - Re - Mi - Sol |

## 5. 六声/七声扩展策略

### 5.1 分类

| 类别 | 定义 | 在本项目中的处理 |
|------|------|-----------------|
| **五声调式** | 仅用宫商角徵羽 | 主体，默认模式 |
| **六声调式** | 五声 + 变宫(Si) 或 清角(Fa) | 允许，通过Prompt参数控制 |
| **七声调式** | 五声 + 变徵(#Fa) + 变宫(Si) | 允许，用于特定场景如"释放愤怒"需张力时 |

### 5.2 Prompt 中的音阶约束语句

```
以中国传统五声音阶（宫商角徵羽，对应Do-Re-Mi-Sol-La）为主体旋律框架。
可适当加入经过音、装饰音以增强音乐性。
整体保持中国民族音乐风格。
```

> 注意：**不写**"禁止Fa和Si"——换成正向约束"以五声为主体"。

## 7. 设计决策记录

| 决策 | 结论 | 依据 |
|------|------|------|
| Fa和Si是否禁止？ | **不禁止**，以五声为主体，允许经过音/装饰音 | 《山东中医杂志》2024，《中医五行音乐疗法的研究进展》 |
| 疗愈方向的决定因素？ | **调式中心**，不是音阶中是否混入非五声音符 | 五音对应五脏理论 |
| Prompt中如何约束？ | 正向约束"以五声为主体"，不写负面禁止 | AI生成容错性更好 |
