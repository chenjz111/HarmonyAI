# 版本来源、开发分支与历史边界

## 为什么在 main 展示 S6 快照

本仓库的 GitHub 默认分支用于让招聘人员直接查看 HarmonyAI 的实际团队工程，不以此覆盖正在进行的 Sprint 7、Sprint 8 开发分支。此次展示以已有 S6 产品恢复提交 `8e32975607fe96f56852a2b7f7c0ae8f959cb191` 的指定文件为输入，521 个上游业务/配置文件复用其原始 Git Blob，不在 main 合并或改写 S6 提交历史。

展示提交的父提交为原始 main `30b72cff6ce90f820aca13c19577b242ffcdddb7`。具体路径、源 Blob、SHA-256 和作者未知项记录于 [SOURCE_MANIFEST.csv](SOURCE_MANIFEST.csv)。整个工程由团队共同研发，并使用 AI 辅助工具；文件快照整理不等于宣称本人独立开发全部代码。

## 对后续 Sprint 7/8 的影响

- 本展示版本不会修改 `dev`、`team/s7-m1-w2-baseline` 或其他现有开发分支的提交、工作树和内容；无需强制推送。
- 开发分支继续基于它们自己的既有历史推进。未来若将 Sprint 7/8 的业务实现合并到 main，需要单独审查与 S6 快照的重叠代码及冲突；不能承诺零冲突，也不建议盲目把本展示提交 merge/rebase 到开发分支。
- 默认分支保护规则要求 Pull Request 和独立审核，正式合并以 GitHub 实际审批状态为准。
- GitHub main 仅是一个公开代码入口，并不代表最新生产发布版本；查看各 Sprint 特性请使用对应开发分支。

## 纳入与排除

本展示包含 521 个指定真实工程/配置文件以及 9 个展示、来源和验证说明文件。没有加入真实用户数据库、医学知识资产、音频、图片、字体、环境配置、种子数据和真实运行日志。当前不保证完整 App、RAG 和 H5 构建可从零运行。测试记录见 [VERIFICATION.md](VERIFICATION.md)。

项目负责人于 2026-10-24 确认所选团队源码可供公开求职展示。该确认不等于获得全部成员作者证明，也不自动授予 MIT 等再使用许可或覆盖第三方素材。逐文件实际作者无法确认的仍标记 UNKNOWN。

## 现存 Git 历史风险

此前公开开发历史曾因测试暂存目录意外纳入 36 个 SQLite 文件条目（30 个不同 Blob），之后从开发分支现有文件树中删除。根据生成这些数据库的测试代码，路径与内容来源高度符合临时合成测试；但未对全部二进制内容逐项做隐私审计。本展示新提交没有继承这些旧开发提交，也不能清除其他公开分支中的历史对象。

原始 main 早期历史中已有两张 PNG；当前展示文件树不再包含它们，但旧提交中的对象仍然存在。不要把“当前目录干净”误认为“仓库所有历史都已清场”。

本次不执行旧分支历史重写、全仓清理或删改他人成果。
