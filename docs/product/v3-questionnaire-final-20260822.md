# 第二部分：身体状态（Q6-Q10，多选）

> 引导语："再看看身体的感觉，有就有、没有就没有，选'都很少出现'就好。"
> 交互：柔和人体轮廓/场景图 + 文字选项（图文混排）

### Q6 肝·身体
> 下面这些感觉，最近一周有没有出现过？

| 选项 | 文案 | 后台 |
|------|------|------|
| A | **胸口附近**有时会觉得**闷闷的，想长舒一口气** | `flank_discomfort` → 肝 |
| B | **身体**某些部位会觉得**紧绷、伸展不开** | `tendon_stiffness` → 肝 |

# 补充页：疗愈诉求（选填，独立一步）

> 位置：主问卷 10 题完成后，单独一页。
> 性质：**选填、可跳过**（页面上有"暂时跳过"按钮）。
> 形式：**选项卡 + 可选文字**——用户可点选 1-2 个诉求，也可在输入框里写下自己的话（两个都可留空）。

### 引导语
> "最后，如果想的话，告诉一下我们：现在最希望音乐帮你做点什么？（不填也没关系，可以直接跳过）"

### 选项卡（最多选 2 项，第 1 项为主诉求）

| 选项 | 文案 | 后台（UserGoal）|
|------|------|----------------|
| A | 帮我**睡得安稳一点** | `sleep` |
| B | 让我**放松、静下来** | `relaxation` |
| C | 帮我**把情绪释放出来** | `emotion_regulation` |
| D | 让我**更容易专注** | `focus` |
| E | 帮我**恢复点精力** | `energy` |
| F | 让我**减轻点压力** | `stress_relief` |
| G | 其他 | `other` |

### 可选文字（填空题）
> "如果你愿意，也可以用自己的话补充（比如：'想听点安静的雨声'、'希望音乐像流水一样'）——不超过 200 字。"

```json
// 后台输出（对齐合同 §2.5 UserGoal）
{
  "primary_goal": "sleep",            // 第 1 项；未选则为 null
  "secondary_goal": "relaxation",     // 第 2 项；可空
  "custom_goal_text": "想听点安静的雨声"  // 自由填空；可空
}
```

- **可整页跳过** → 后台输出 `user_goal = null`，不影响主流程
- **用途**：为音乐生成提供环境/节奏参数（sleep → 慢节奏；emotion_regulation → 释放型；custom 文本进入 Agent3 参数参考）
- **说明**：`primary_goal=other` 时建议引导填写文字；其余选项文字选填
