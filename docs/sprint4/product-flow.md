## 一、完整用户旅程

```
┌─────────────────────────────────────────────────────────┐
│                 阶段性完整评估 (首次/定期)                   │
│                                                         │
│  STEP 1: 上传材料 (可选)                                  │
│    → 选择文件 (JPG/PNG/PDF, ≤10MB, PDF≤3页)              │
│    → OCR 处理中 (spinner)                                │
│    → OCR 结果展示 + 置信度                                │
│    → 用户编辑/确认/跳过                                   │
│                                                         │
│  STEP 2: 自由描述 (可选)                                  │
│    → 文本输入 (max 500字)                                │
│    → "最近发生了什么？感觉怎么样？"                         │
│    → 隐私提示: 不填姓名/电话/身份证                         │
│                                                         │
│  STEP 3: 20题完整问卷 (必填)                              │
│    → A. 目标与感受 (2题)                                  │
│    → B. 紧张思虑激活 (5题)                                │
│    → C. 低落与积极体验 (4题)                              │
│    → D. 睡眠精力身体 (5题)                                │
│    → E. 持续时间与影响 (2题)                              │
│    → F. 安全筛查 (2题)                                    │
│    → 进度条 + 保存恢复                                    │
│                                                         │
│  STEP 4: AI 分析                                         │
│    → Loading: "正在分析你的状态..."                        │
│    → 显示处理进度:                                        │
│      ✓ 问卷评分完成                                       │
│      ✓ 文本分析完成 (or ⚠ Qwen不可用)                     │
│      ✓ 材料分析完成 (or — 未上传)                          │
│      ✓ 多源融合完成                                       │
│                                                         │
│  STEP 5: 评估结果                                         │
│    → 数据来源状态 (问卷✓ 文本✓ 材料—)                       │
│    → 状态摘要                                             │
│    → 情绪维度 (带证据来源)                                  │
│    → 身体信号                                             │
│    → 生活事件                                             │
│    → 冲突信息 (如有)                                       │
│    → 缺失信息 (如有)                                       │
│                                                         │
│  STEP 6: 动态追问 (0-6题)                                 │
│    → "为了更好地理解你，请回答以下问题:"                     │
│    → 追问 1-N                                             │
│    → 提交 → 重新生成评估 (revision+1)                      │
│                                                         │
│  STEP 7: 用户确认                                         │
│    → "以下评估结果是否准确？"                               │
│    → [完全准确] [部分准确] [不准确]                         │
│    → 可逐项修正                                           │
│    → 确认后进入 Diagnosis                                  │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│              Diagnosis Agent — 辅助辨证                   │
│                                                         │
│  → 基于确认后的证据                                       │
│  → 输出候选倾向 + 支持/反对证据                            │
│  → 证据不足时: abstained=true                            │
│  → 展示 reasoning_summary                                │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│              Prescription → Music → Feedback             │
│              (保持 Sprint 3 现有实现)                      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│              每次使用前: Quick State (6题)                 │
│                                                         │
│  听前:                                                   │
│    1. 此刻紧张或担忧程度 (0-10)                            │
│    2. 此刻思绪反复程度 (0-10)                              │
│    3. 此刻情绪低落程度 (0-10)                              │
│    4. 此刻身体紧绷程度 (0-10)                              │
│    5. 此刻精神疲惫程度 (0-10)                              │
│    6. 这次希望达到的目标                                  │
│                                                         │
│  → 获取音乐处方 → 播放                                    │
│                                                         │
│  听后: 重复 1-5                                           │
│  → Feedback Agent 计算 delta                             │
└─────────────────────────────────────────────────────────┘
```

## 二、20 题问卷与 6 题快速问卷的关系

| | 20 题完整评估 | 6 题快速状态 |
|---|---|---|
| 时机 | 首次使用 / 两周 / 状态变化 | 每次听音乐前 |
| 题数 | 20 | 6 |
| 时间 | 3-5 min | 30-60 sec |
| 输出 | Assessment + Diagnosis | Quick State |
| 可跳过 | 否 (必填) | 否 (必填) |
| 版本 | questionnaire_v2.1 | quick_state_v1 |

## 三、动态追问与用户确认的关系

```
Assessment 初步结果
  ├── evidence_coverage ≥ 70% 且无冲突 → 直接进入确认
  ├── evidence_coverage < 70% 或有冲突 → 生成追问
  │     └── 用户回答 → 重新生成 Assessment (revision+1)
  └── 用户确认
        ├── 完全准确 → 进入 Diagnosis
        ├── 部分准确 → 用户修正 → revision+1 → 重新确认
        └── 不准确 → 用户重新填写关键信息 → revision+1
```

## 四、状态展示规范

### 4.1 情绪维度展示

不使用 0-100 原始分数。使用分层展示：

| 原始均值 | 展示文本 |
|---|---|
| 0 - 0.75 | 当前不明显 |
| 0.76 - 1.75 | 轻微出现 |
| 1.76 - 2.75 | 有一定表现 |
| 2.76 - 3.50 | 较明显 |
| 3.51 - 4.00 | 持续或非常明显 |

### 4.2 数据来源标签

每个结论旁边显示来源标签:
- `问卷` — 来自 20 题问卷
- `文本` — 来自自由描述
- `材料` — 来自上传文档
- `追问` — 来自用户补充回答
- `修正` — 用户手动修改

### 4.3 输入处理状态

```
输入来源状态:
  自由描述  ✓ 已完成处理 (提取 8 条证据)
  上传材料  ⚠ OCR 识别中...
  问卷      ✓ 20/20 题完成
```

## 五、与 Sprint 3 的差异

| 功能 | Sprint 3 | Sprint 4 |
|---|---|---|
| OCR | Mock 固定文本 | PaddleOCR 真实识别 |
| 自由文本 | Qwen 不可用时静默忽略 | 明确显示"未使用"状态 |
| 问卷 | 12 题 V2.0 | 20 题 V2.1 + 6 题 Quick |
| 证据 | 简单维度列表 | EvidenceItem 完整结构 |
| 冲突 | 不检测 | Conflict 检测 + 展示 |
| 追问 | 无 | 0-6 题动态追问 |
| 用户确认 | 无 | 多级确认 + 修订 |
| Diagnosis | 总有一个证型 | 可 abstained |
| 评估集 | 无 | 60 个标注案例 |
