# ADR-0005: 不删除 Fa 和 Si

> **状态：** 已采纳
> **日期：** 2026-07-11
> **决策者：** 陈家智（AI Architect）

---

## 背景

西方七声音阶（Do/Re/Mi/Fa/Sol/La/Si）中的 Fa 和 Si 不在中医五音（宫/商/角/徵/羽）中。音乐生成时是否要完全禁止 Fa 和 Si？

## 决策

**不禁止 Fa 和 Si。以五声音阶为主体，允许六声/七声扩展。**

## 理由

1. **学术文献支持：** 《五行音乐疗法及其择时应用探析》（《山东中医杂志》，2024）明确指出"五音治疗体系由五声调式、六声调式与七声调式共同构成"。
2. **学术界无删除共识：** 国内中医音乐疗法研究没有认为"七声音阶不能用"，也没有形成"必须删除 Fa 和 Si"的统一观点。
3. **疗效取决于调式中心，非音阶纯洁度：** 疗愈方向由调式主音决定（角调以 Mi 为主音），而非音阶中是否混入非五声音符。
4. **AI 生成容错性：** Prompt 中写"禁止 Fa 和 Si"可能导致 AI 生成结果僵硬。正向约束（"以五声音阶为主体"）比负向禁止更有效。

## Prompt 策略

```
❌ 不写："禁止使用 Fa 和 Si"
✅ 改为："以中国传统五声音阶（宫商角徵羽 = Do-Re-Mi-Sol-La）为主体旋律框架，
         可适当加入经过音、装饰音以增强音乐性。整体保持中国民族音乐风格。"
```

## 后果

- **正面：** 音乐生成结果更自然、更丰富。有学术文献支撑，答辩时有据可依。
- **正面：** 保留 Fa 和 Si 作为"经过音"和"装饰音"，增强了音乐性而不伤害五音的主体地位。
- **负面：** 如果 AI 模型不理解"五声为主体"，可能生成偏离五音风格的音乐。需要通过 Prompt 模板的约束语句来控制。
