# HarmonyAI Questionnaire V2 规格

> 用途：比赛版状态问卷  
> 目标时长：不超过 3 分钟  
> 题目数量：12 题  
> 时间范围：除特别说明外，均指“过去 7 天”

## 1. 设计目标

Questionnaire V2 是多源评估中的稳定基线。它不是医学量表的替代品，也不能独立完成医学诊断。其作用是以简短、易理解的方式收集用户的情绪、睡眠、精力、食欲和日常影响，并为 Assessment Agent 提供确定性的结构化输入。

设计原则：

- 用户不需要先选择“怒喜思悲恐”；
- 现代生活语言优先，中医情志映射在评估阶段完成；
- 核心题统一使用 0—4 频率量表；
- 图形只帮助表达，不能成为隐蔽的医学硬编码；
- 天气类比只作体验和上下文，不单独决定辨证；
- 所有问卷分数可复现，不由 Qwen 自由生成；
- 风险规则优先级高于普通评分；
- 输出只能称“状态评估”或“辅助辨证倾向”。

## 2. 统一量表

Q2—Q11 使用同一频率量表：

| 分值 | 标签 | 辅助说明 |
|---:|---|---|
| 0 | 从不 | 过去 7 天没有出现 |
| 1 | 偶尔 | 出现 1—2 天 |
| 2 | 有时 | 出现 3—4 天 |
| 3 | 经常 | 出现 5—6 天 |
| 4 | 几乎每天 | 基本每天出现 |

交互要求：

- 每次只显示 1 题；
- 选择后可自动进入下一题，但必须允许返回修改；
- 顶部显示进度，例如“4 / 12”；
- 所有选项同时提供文字，不能只用颜色或图形；
- 预计单题 8—12 秒，总时间控制在 3 分钟内。

## 3. 12 题草案

### Q1 今日内在天气

- 问题：如果把你此刻的内在感受比作一种天气，哪一张最接近？
- 交互：5 张天气图标卡片。
- 选项：晴朗、微云、阴天、下雨、雷雨。
- 计分：不进入核心总分，仅作为用户表达标签 `mood_metaphor`。
- 用途：降低进入问卷的压力，为结果页提供用户可理解的表达。
- 限制：不得使用“雷雨 = 愤怒 = 肝 = 角调”等直接映射。

### Q2 紧张与担忧

- 问题：过去 7 天，你有多常感到紧张、担心，或很难放松？
- 交互：0—4 文字频率按钮。
- 维度：`tension_worry`。

### Q3 思绪像海面一样停不下来

- 问题：过去 7 天，你有多常反复想同一件事，脑子很难停下来？
- 交互：5 张海面图形卡片，从平静到浪涌，同时显示 0—4 频率文字。
- 维度：`overthinking`。
- 限制：海浪强度只是频率的视觉表达，不直接映射证型。

### Q4 烦躁与易怒

- 问题：过去 7 天，你有多常感到烦躁、容易生气或对小事失去耐心？
- 交互：0—4 频率按钮，可配中性表情图标。
- 维度：`irritability_anger`。

### Q5 情绪低落

- 问题：过去 7 天，你有多常感到情绪低落、难过或提不起精神？
- 交互：0—4 频率按钮。
- 维度：`low_mood`。
- 文案限制：不在问题或结果中直接使用疾病诊断词。

### Q6 兴趣下降

- 问题：过去 7 天，你有多常对原本喜欢的事情缺少兴趣？
- 交互：0—4 频率按钮。
- 维度：`interest_loss`。

### Q7 恐惧与不安

- 问题：过去 7 天，你有多常感到不安、害怕，或担心会发生不好的事情？
- 交互：0—4 频率按钮。
- 维度：`fear_unease`。

### Q8 睡眠困扰

- 问题：过去 7 天，你有多常出现入睡困难、容易醒、睡不踏实或醒后仍疲惫？
- 交互：0—4 频率按钮，配月亮和床的图标。
- 维度：`sleep_disturbance`。

### Q9 精力电池

- 问题：过去 7 天，你有多常觉得精力不足，像“电量不够”？
- 交互：5 张电池图形卡片；图形从满电到空电，但下方仍显示 0—4 频率。
- 维度：`low_energy`。
- 无障碍：选项文字为“从不精力不足”至“几乎每天精力不足”，避免满电方向造成误选。

### Q10 食欲变化

- 问题：过去 7 天，你有多常出现明显没胃口、吃得过多，或食欲和平时差别较大？
- 交互：0—4 频率按钮，配餐盘图标。
- 维度：`appetite_change`。

### Q11 日常影响

- 问题：过去 7 天，上述状态有多常影响你的学习、工作、休息或与人相处？
- 交互：0—4 频率按钮。
- 维度：`daily_impact`。

### Q12 身体感受与安全检查

- 问题：你现在是否有以下情况？可多选。
- 交互：图标卡片多选，另有“以上都没有”。
- 普通选项：肩颈紧张、头痛或头沉、心慌、胃部不适、身体疲惫、其他。
- 高风险选项：严重或持续胸痛、明显呼吸困难、有伤害自己的想法。
- 计分：普通选项仅作 `physical_signals`，不直接计入证型或音乐调式；高风险选项进入 `safety_flags`。
- 规则：选择“以上都没有”时清除其他选项；选择高风险项时立即显示安全提示。

## 4. 图形题设计

至少使用以下 4 类图形题：

1. Q1 天气卡：表达此刻整体感受；
2. Q3 海面卡：表达反复思虑出现的频率；
3. Q9 电池卡：表达精力不足；
4. Q12 身体图标卡：辅助选择身体感受和风险信号。

视觉要求：

- 每张图必须有文字标签和选中态；
- 不依赖红、绿颜色区分；
- 不使用可引导用户自我诊断的脏腑图；
- 不将五音、五行作为答案选项；
- 动画可有但不能拖慢答题；
- 图形资源应明确版权或由团队自制。

## 5. 计分维度

### 5.1 单维度分数

Q2—Q11 每题的原始分为 0—4，展示层可归一化为 0—100：

```text
normalized_score = raw_score × 25
```

### 5.2 组合摘要

组合摘要只用于状态展示，不直接等于疾病或中医证型：

- 紧张负担：Q2、Q7 平均；
- 反复思虑：Q3；
- 烦躁状态：Q4；
- 低落与兴趣：Q5、Q6 平均；
- 身体与生活负担：Q8、Q9、Q10、Q11 平均。

建议严重程度标签：

| 归一化分数 | 用户端标签 |
|---:|---|
| 0—24 | 当前较少 |
| 25—49 | 轻度出现 |
| 50—74 | 较明显 |
| 75—100 | 频繁出现 |

这些标签表示过去 7 天的主观频率，不代表临床严重程度。

### 5.3 与多源评估的关系

- 问卷原始答案和确定性分数为不可被 LLM 覆盖的事实；
- Narrative 可补充事件、持续时间和用户语言；
- Document 可补充已有医疗材料中的症状、诊断描述、用药和医生建议；
- Assessment Agent 可做归纳和来源对照，但必须保留原始维度；
- Diagnosis Agent 应基于多个维度、已审核知识和上下文产生“辅助辨证倾向”；
- 禁止根据 Q12 的单一身体选项直接得出某脏腑、证型或调式。

## 6. 问卷 JSON 建议结构

以下为拟议的 v2 结构，不是当前已存在接口：

```json
{
  "schema_version": "questionnaire_v2.0",
  "time_window_days": 7,
  "started_at": "2026-07-28T19:30:00+08:00",
  "completed_at": "2026-07-28T19:32:15+08:00",
  "answers": [
    {
      "question_id": "q01_mood_weather",
      "type": "visual_single",
      "value": "cloudy",
      "score": null
    },
    {
      "question_id": "q02_tension_worry",
      "type": "frequency_0_4",
      "value": 3,
      "score": 3
    },
    {
      "question_id": "q12_physical_safety",
      "type": "visual_multi",
      "value": ["neck_tension", "fatigue"],
      "score": null
    }
  ],
  "dimension_scores": {
    "tension_worry": 75,
    "overthinking": 75,
    "irritability_anger": 25,
    "low_mood": 50,
    "interest_loss": 25,
    "fear_unease": 25,
    "sleep_disturbance": 75,
    "low_energy": 75,
    "appetite_change": 50,
    "daily_impact": 50
  },
  "context": {
    "mood_metaphor": "cloudy",
    "physical_signals": ["neck_tension", "fatigue"]
  },
  "safety_flags": [],
  "completion_seconds": 135
}
```

字段约束：

- `schema_version` 必填；
- Q2—Q11 必须全部作答且只能为整数 0—4；
- Q1 和 Q12 不进入核心总分；
- `dimension_scores` 由后端重新计算，不能信任前端提交值；
- `safety_flags` 由前后端分别检测，后端为最终门禁；
- 原始答案保留，以便解释和测试；
- 不保存未经必要化处理的额外敏感内容。

## 7. 安全规则

### 7.1 立即安全提示

以下任一情况触发 `urgent_attention`：

- 有伤害自己或结束生命的想法；
- 严重或持续胸痛；
- 明显呼吸困难。

处理：

1. 当前页面立即显示醒目提示；
2. 禁止用“听音乐即可缓解”替代专业帮助；
3. 后端再次检测并返回机器可读风险代码；
4. 常规处方工作流暂停；
5. 用户可以返回修改误选，但修改行为应留在本次会话审计摘要中；
6. 具体紧急联系方式必须依据上线地区和正式合规方案配置，不能由模型猜测。

### 7.2 非紧急但需关注

以下情况提示进一步关注，但不自动阻断：

- Q11 = 4；
- Q8 = 4 且持续时间信息显示超过两周；
- 多个核心维度同时为 4；
- OCR 或文本出现“症状明显加重”等描述但不满足急性危险规则。

### 7.3 风险检测来源

风险检测必须同时覆盖：

- 问卷 Q12；
- 自由描述关键词与结构化提取；
- 用户确认后的 OCR 文本；
- Qwen 输出后的二次规则校验。

Qwen 不可用时，确定性风险规则仍必须生效。

## 8. 结果表述边界

允许：

- “你过去 7 天较常出现紧张和反复思虑。”
- “结合你提供的信息，系统识别到睡眠和精力也受到影响。”
- “以下为用于音乐调养的辅助辨证倾向。”

不允许：

- “你患有焦虑症。”
- “系统诊断你为心脾两虚。”
- “选择胸闷说明心脏有病。”
- “听完本处方可以治愈失眠。”

固定免责声明：

> 本结果用于状态整理和音乐调养参考，不构成医学诊断，也不能替代医生或心理专业人员的评估。如有明显或持续不适，请及时寻求专业帮助。

## 9. 验收标准

- 题目总数固定为 12；
- 正常阅读速度下 3 分钟内完成；
- Q2—Q11 全部使用统一 0—4 频率量表；
- 覆盖指定 10 个核心维度；
- 至少 3 题具有图形/图标卡片；
- 天气题不进入核心评分；
- 身体选项不直接映射脏腑、证型或调式；
- 前后端都能识别高风险选项；
- 问卷分数可由相同答案稳定复算；
- 页面和 API 均不输出医学诊断。
