- Base 是 `dev`；

- 测试结果与变更范围相称；
- P0 降级和兼容路径没有被删除。

## 4. 安全和隐私

- [ ] `.env` 未进入 Git
- [ ] 仓库历史和本次 Diff 未发现 API Key
- [ ] `.env.example` 只包含占位符
- [ ] 演示材料均为虚构或脱敏材料
- [ ] 上传接口校验扩展名、MIME、文件签名、大小和页数
- [ ] 未确认 OCR 文本不进入可靠评估来源
- [ ] 日志不记录病例全文和身份证号等敏感信息
- [ ] 临时材料有清理策略
- [ ] 自伤、严重胸痛和呼吸困难可触发确定性安全门禁
- [ ] 页面固定展示非医学诊断声明

## 5. 产品真实性

- [ ] 没有把状态评估写成医学诊断

- [ ] 可信度没有被描述为疾病概率或医学准确率
- [ ] Feedback 只更新个人偏好
