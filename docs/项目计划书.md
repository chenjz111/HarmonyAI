## 一、项目概述

### 1.1 项目名称

五音疗愈平台 —— 基于中医五音理论的 AI 音乐辅助调理系统

### 1.2 一句话定位

> **中医知识驱动的 AI 音乐干预决策系统。** APP 是展示形式，AI 音乐是输出结果，核心技术是中间那套"中医知识 → 音乐参数 → AI 生成"的决策引擎。

### 1.3 团队

- 五人团队 + 一位指导老师
- **陈家智**：Project Leader & AI Architect
- **钟睿宸**：AI Engineering Lead
- **蔡子鑫**：Backend Platform Engineer
- **彭翔**：Client Engineer
- Medical Knowledge Engineer：**肖宇翔**
- 详细分工见 `docs/团队分工书.md`

### 1.5 核心理念

> HarmonyAI 不是一个音乐生成项目，而是一个**基于知识驱动（Knowledge-Driven）的可解释多智能体音乐疗愈系统**。

### 1.4 命名规范

| ❌ 禁止 | ✅ 使用 |
|--------|--------|
| 音乐治疗 | AI 音乐辅助调理 / 健康管理 |
| 治疗/疗效 | 干预 / 调理 / 辅助改善 |
| 病人 | 用户 |

## 二、系统架构

### 2.1 三层架构 + 五Agent 叠加

```
第一层：医学分析层
  ① 评估Agent（检测仪：信息采集 + 量化）
     ↓
  ② 中医辨证Agent（诊断大脑：证候判断 + 可信度）
    输出：中医结论（不提音乐）

第二层：知识映射层 🔥 核心创新
  ③ 音乐处方Agent（开方子：中医语言→音乐参数）
    输出：每日处方 + Prompt参数 + 推荐理由

第三层：AI生成层
  ④ 音乐生成Agent（煎药机：调API→音频）
     ↓
  ⑤ 用户反馈Agent（复诊：效果判断→继续/微调/重辨证）
    输出：反馈决策 + 用户画像更新
```

### 2.2 五Agent 一句话

| Agent | 类比 | 职责 |
|-------|------|------|
| ① 评估 | 检测仪器 | 采集量化，输出健康画像 |
| ② 辨证 | 诊断大脑 | 证候判断，输出证型+可信度 |
| ③ 处方 | 开方子 | 中医→音乐参数映射 |
| ④ 生成 | 煎药机 | API调用，输出音频 |
| ⑤ 反馈 | 复诊 | 效果评估，闭环优化 |

## 三、核心技术决策

### 3.1 七音→五音映射

**结论：以五声音阶为主体，允许六声/七声扩展，不禁止 Fa/Si。**

文献依据：《山东中医杂志》2024 指出"五音治疗体系由五声调式、六声调式与七声调式共同构成"。

工程策略：Prompt 中正向约束——"以中国传统五声音阶为主体，可适当加入经过音、装饰音"。

### 3.2 五音对应关系

| | 宫 | 商 | 角 | 徵 | 羽 |
|---|----|----|----|----|----|
| **西方音** | Do(C) | Re(D) | Mi(E) | Sol(G) | La(A) |
| **五行** | 土 | 金 | 木 | 火 | 水 |
| **五脏** | 脾 | 肺 | 肝 | 心 | 肾 |
| **情绪** | 思 | 悲 | 怒 | 喜 | 恐 |
| **BPM** | 60-68 | 68-76 | 65-75 | 70-80 | 55-65 |
| **乐器** | 古琴、编钟 | 二胡、钹 | 古筝、竹笛 | 琵琶、铜铃 | 古琴、磬 |
| **环境音** | 大地 | 秋风 | 流水/森林 | 鸟鸣 | 雨声/海洋 |

### 3.3 权重映射（非固定 1对1）

肝郁化火 → {角:0.75, 宫:0.15, 羽:0.10}，而非 角:100%

权重可通过用户反馈数据持续优化。

### 3.4 知识库：四层结构

1. 经典文献（《黄帝内经》《伤寒论》等）
2. 现代论文（近五年五音疗法 RCT 研究）
3. 专家经验（中医师临床选调实践）
4. 用户反馈数据（持续进化）

### 3.5 Prompt 策略

数据库只存参数（调式/BPM/乐器），不存完整 Prompt 字符串。运行时由模板引擎自动组装。

### 3.6 每日处方（非单曲）

默认输出 7 天处方序列，每天调式权重渐次变化，符合中医"调理"理念。

### 3.7 可信度体系

每个 Agent 输出带 `confidence` 字段。辨证可信度 < 40% 时，系统提醒"建议咨询专业中医师"。

### 3.8 可解释性

每个处方附带推荐理由，引用文献原文（如《黄帝内经》"肝属木，木对应角音"）。

### 3.9 反馈系统

主观评分 + 行为数据 + 可穿戴设备预留（心率/HRV/睡眠/呼吸）。

## 七、当前任务：Sprint 1 五行生克规则矩阵

### 要做的事

将情绪→五行→五音→调式→BPM→乐器的映射链，写成一张完整的、可编码的规则表。覆盖所有常见证型。

### 五层映射链

```
情绪分数 → 五行+五脏 → 五音+权重 → 音乐参数(BPM/乐器/环境音) → 生克选调 → 每日处方编排
```

### 需要定义的规则

1. 情绪→五行对照（焦虑→怒→木→肝，抑郁→悲→金→肺 等）
2. 每个证型的主调权重矩阵（如肝郁化火→{角:0.75, 宫:0.15, 羽:0.10}）
3. 五行生克辅调选择规则（木克土→辅宫，金克木→不选商 等）
4. 各调式的BPM范围与证候严重程度的对应调整
5. 各调式的乐器推荐与冲突检测
6. 7日处方编排策略（权重渐变规则）
