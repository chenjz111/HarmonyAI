# R1 密码资源准入候选

依现有R1 C4/C8资源与并发要求，不新增账号产品功能。所有PasswordPolicy实例在同一进程共享至多4个Argon2计算槽（约76MiB算法内存，不含解释器/库开销），拒绝排队无限积压；4是保守候选上限，不代表生产负载签收。多进程/多实例总预算仍需部署验收。

参数、NFC/密码规则、数据库会话/Refresh语义完全保持。无槽位时返回既有ACCOUNT_UNAVAILABLE 503；校验繁忙不能伪装成密码错误。绑定哈希失败发生在身份事务之前，Guest不转换；登录事务中的繁忙回滚。槽位必须在计算异常后释放。不触发客户端自动重放。

顺序：确定性饱和RED（包括真实API绑定）；实现共享非阻塞槽和既有服务异常适配；GREEN/原R1回归；本机实际Argon2合成负载记录；独立审查后提交。无新依赖/打包/设备/公开路由授权。
